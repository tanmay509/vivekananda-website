Courses & Syllabus

Choose from our comprehensive range of computer courses designed for beginners to advanced learners.

3 Months

DCA (Diploma in Computer Applications)

Course Content

  • Fundamentals of Computer & Operating System
  • MS Word, Excel, PowerPoint
  • Internet & Email
  • Tally ERP Basics
  • DTP (PageMaker, CorelDRAW)

Module 1: Computer fundamentals, hardware & software basics

Module 2: Windows OS, file management, settings

Module 3: MS Office suite — documents, spreadsheets, presentations

Module 4: Internet browsing, email, online safety

Module 5: Tally accounting software introduction

Module 6: Desktop publishing & practical project

4 Months

Programming in C & C++

Course Content

  • Introduction to Programming Logic
  • Variables, Data Types & Operators
  • Control Structures & Loops
  • Functions & Arrays
  • OOP Concepts in C++

Module 1: Algorithm & flowchart design

Module 2: C programming — syntax, I/O, operators

Module 3: Decision making, loops, switch-case

Module 4: Functions, recursion, arrays, strings

Module 5: Pointers, structures, file handling

Module 6: C++ — classes, objects, inheritance, polymorphism

3 Months

Python Programming

Course Content

  • Python Basics & Syntax
  • Data Structures & Collections
  • Functions & Modules
  • File Handling & Exception Handling
  • Introduction to Django / Flask

Module 1: Python installation, IDE setup, basics

Module 2: Variables, data types, operators, strings

Module 3: Lists, tuples, dictionaries, sets

Module 4: Conditional statements, loops, comprehensions

Module 5: Functions, lambda, modules, packages

Module 6: OOP, file I/O, error handling, mini project

6 Months

Full Stack Web Development

Course Content

  • HTML5, CSS3 & Responsive Design
  • JavaScript & DOM Manipulation
  • React.js Fundamentals
  • Node.js & Express.js
  • MongoDB & REST APIs

Module 1: HTML5 semantic tags, forms, accessibility

Module 2: CSS3, Flexbox, Grid, Tailwind CSS

Module 3: JavaScript ES6+, async/await, fetch API

Module 4: React components, hooks, state management

Module 5: Node.js backend, Express routing, middleware

Module 6: MongoDB, authentication, full-stack project

Module 4: Stock groups, godowns, purchase & sales

Module 5: Balance sheet, P&L, cash flow statements

Graphic Design & DTP
